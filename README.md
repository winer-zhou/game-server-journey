# 多人实时游戏服务器（Go）

基于 Go 实现的 TCP 长连接游戏服务器。支持多房间、实时位置同步、断线重连、
Redis 排行榜持久化，并提供 HTTP 监控接口、终端地图客户端与 HarmonyOS 客户端。

## 功能

| 模块 | 说明 |
|---|---|
| **TCP 长连接** | goroutine 每连接并发模型，压测单机 10000 并发连接 |
| **多房间** | 房间隔离，房间内广播，不同房间互不可见 |
| **位置同步** | `move x y` 指令广播给同房间所有玩家 |
| **粘包处理** | 行分隔协议 + `bufio.Scanner` 按行解析 |
| **发送队列** | channel 解耦网络 IO，慢客户端队列满自动踢出（背压处理） |
| **并发安全** | `sync.RWMutex` 保护连接列表，读多写少场景读操作可并发 |
| **心跳保活** | `SetReadDeadline` 超时踢人 + 客户端 `ping` 续命 |
| **优雅关闭** | `context` + `signal` + `WaitGroup`，等待所有连接退出 |
| **断线重连** | token 会话机制，恢复房间 / 昵称 / 位置 |
| **错误隔离** | `handleConn` 内 `recover`，单连接 panic 不影响服务器 |
| **排行榜** | Redis ZSET 实现，积分持久化，重启不丢 |
| **HTTP 监控** | `/health` 健康检查、`/status` 全局状态、`/room/{name}` 按房间查询 |
| **日志中间件** | 记录每个 HTTP 请求的方法、路径与耗时 |
| **单元测试** | `parseMove` 覆盖 12 个分支场景，覆盖率 100% |
